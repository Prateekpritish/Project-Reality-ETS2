# PROJECT REALITY – REALISTIC SKY

A realistic sky replacement mod for **Euro Truck Simulator 2**.

## Features
- Realistic sky textures.
- Optimized BC6H texture compression.
- Reduced mod archive size.
- Designed for ETS2 version 1.61.

## Installation
1. Download the `.scs` file from the **Releases** section.
2. Copy it into:
   `Documents/Euro Truck Simulator 2/mod`
3. Launch Euro Truck Simulator 2.
4. Open Mod Manager and enable **PROJECT REALITY – REALISTIC SKY**.
5. Apply changes and enjoy!

## Compatibility
- Euro Truck Simulator 2: 1.61
- Mod type: Standalone sky replacement
- Package format: `.scs`
